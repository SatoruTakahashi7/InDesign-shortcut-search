# ショートカット検索 JSX版 v1.0.3

`ショートカット検索.jsx`だけで動作する単体版です。

## インストール

1. InDesignで「ウィンドウ → ユーティリティ → スクリプト」を開きます。
2. スクリプトパネルの「ユーザー」を右クリックし、「Finderで表示」を選びます。
3. `ショートカット検索.jsx`をそのフォルダへコピーします。
4. スクリプトパネルに表示された`ショートカット検索.jsx`をダブルクリックします。

## 主な機能

- プリセット／ユーザー`.indk`の検出と任意ファイル読込
- コマンド名・キー・機能エリアの検索
- コマンドの実行
- モーダル画面によるショートカット記録
- ショートカットの追加、競合置換、個別削除
- プリセットは別名保存、ユーザーセットは上書き
- ウィンドウサイズと「設定済みのみ」の状態を次回起動時に復元

ScriptUIパレットのため、InDesignのパネル領域へのドッキング、パネルタブのアイコン表示、ZXP管理画面への登録には対応しません。
