# ショートカット検索 JSX版 v1.0.10

`ショートカット検索.jsx`だけで動作する単体版です。

GitHub: [SatoruTakahashi7/InDesign-shortcut-search](https://github.com/SatoruTakahashi7/InDesign-shortcut-search)

## インストール

1. InDesignで「ウィンドウ → ユーティリティ → スクリプト」を開きます。
2. スクリプトパネルの「ユーザー」を右クリックし、「Finderで表示」を選びます。
3. `ショートカット検索.jsx`をそのフォルダへコピーします。
4. スクリプトパネルに表示された`ショートカット検索.jsx`をダブルクリックします。

## 主な機能

- プリセット／ユーザー`.indk`の検出と任意ファイル読込
- コマンド名・キー・機能エリアの検索
- コマンドの実行
- モーダル画面によるショートカット記録
- ショートカットの追加、競合置換、個別削除
- プリセットは別名保存、ユーザーセットは上書き
- ウィンドウサイズと「設定済みのみ」の状態を次回起動時に復元

## v1.0.4での修正

- ユーザーセットの上書き・削除時に、選択中の`.indk`ファイルそのものを更新するよう修正
- `Version 19.0-J-bk`のようなバックアップ環境を通常環境として誤検出しないよう修正
- 同名セットの更新後にInDesignへ強制的に再読み込みさせるよう修正
- 削除対象を、選択した割り当てが持つaction-idと内部コマンド名で照合するよう修正
- `Cmd+Shift+Z`と`Shift+Cmd+Z`のような修飾キー順の違いを同じキーとして扱うよう修正

## v1.0.5での修正

- 起動時にInDesignの現在のスクリプト一覧を読み込み、後から追加したスクリプトも検索対象に追加
- スクリプトの割り当てに内部コマンド名を保存し、再読込後に未定義になる問題を修正
- スクリプトの動的なaction-idを、内部識別番号として現在のセッションから自動取得

## v1.0.6での修正

- スクリプトコマンド名から余分な`Scripts Panel`階層を除き、InDesign標準画面と同じ内部名で保存
- スクリプトの内部識別番号をInDesign標準の`0xff000000 + 番号`形式で保存
- ショートカットの割り当て・削除・再読込後も、操作していたコマンドの選択状態を維持

## v1.0.7での修正

- InDesignがスクリプトのファイル名だけを返す場合も、ユーザー／アプリケーション以下のフルパス内部名を保持
- スクリプト割り当てがパネル内だけで表示され、InDesign標準画面では認識されない問題を修正

## v1.0.8での修正

- `Scripts Panel`が独立階層ではなくパス文字列内に連結されて返る場合にも除去
- スクリプトの表示名・保存する内部名・削除時の照合名を、InDesign標準画面と同じ形式に統一

## v1.0.9での修正

- ショートカット入力欄をクリックして、直接キー記録画面を開けるように変更
- 「デフォルト」などのプルダウンがショートカットの適用範囲であることをツールヒントに追記

## v1.0.10での修正

- 読み取り専用入力欄で`click`イベントが発生しないInDesign環境に対応
- 入力欄のマウス押下を直接取得し、キー記録画面を開くように変更

ScriptUIパレットのため、InDesignのパネル領域へのドッキング、パネルタブのアイコン表示、ZXP管理画面への登録には対応しません。
