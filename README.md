# ショートカット検索 JSX版 v1.0.10

`ショートカット検索.jsx`だけで動作する単体版です。

GitHub: [SatoruTakahashi7/InDesign-shortcut-search](https://github.com/SatoruTakahashi7/InDesign-shortcut-search)

## 主な機能

- プリセット／ユーザー`.indk`の検出と任意ファイル読込
- コマンド名・キー・機能エリアの検索
- 対応するInDesignコマンドの実行
- モーダル画面によるショートカット記録
- ショートカットの追加、競合置換、個別削除、保存前の変更取り消し
- プリセットは別名保存、ユーザーセットは上書き
- ウィンドウサイズと「設定済みのみ」の状態を次回起動時に復元

## v1.0.10の主な変更

- 保存後に新規割り当てが消えたように表示される問題を修正
- 内部名のないコマンドをaction-idから復元し、元のコマンド項目へ割り当てを統合
- 保存用の内部名を現在のInDesign付属プリセットから補完
- action-idを標準画面と同じ「基底ID + オフセット」表記に統一し、ID順で保存
- ユーザーセットは同じファイルへ上書き。別名の編集セットは作成しません

### 確認済みの範囲

- 構文チェックと、内部名の復元・保存形式・ID順・上書き処理の検証
- InDesign 2024（19.5.5.168）で、標準画面の割り当てを削除した後、本スクリプトから「テキストフレーム設定...」にShift+Cmd+Bを割り当てて上書き保存
- 再起動なしで標準画面に割り当てが表示され、実際のキー操作で開くことを確認
- 他のコマンド、スクリプト項目、InDesignの他バージョンは今回の実機確認の対象外です

## v1.0.5の主な変更

- 現在のスクリプトパネルを読み込み、後から追加したスクリプトも検索・割り当て対象に追加
- InDesign標準画面に近い「割り当て」「削除」「保存」「変更を取り消す」の操作方式へ変更
- InDesign 2026へ対応
